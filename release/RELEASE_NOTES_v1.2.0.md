# SteamFlow v1.2.0 发布说明

> SteamFlow — 基于 Flutter 的跨平台视频播放器。
> 无广告、完全免费，可自由分享。

---

## 本版本主题：跨设备播放，局域网里的视频也能直接看

v1.2.0 加入了完整的**内网共享**能力：同一局域网内的设备可以互相发现、共享视频文件夹，
在手机上直接播放电脑里的视频，也可以把远端视频一键复制到本机。
同时重做了「选择视频」页面，并为桌面端加入系统托盘常驻。

---

## 新增功能

### 内网共享

- **自动发现**：同一局域网内的 SteamFlow 设备会自动出现在设备列表中，也可手动输入 IP 添加。
- **共享文件夹**：在「内网共享」页打开「共享本机视频」后，其他设备即可浏览本机的共享文件夹。
- **共享源与混合播放**：共享文件夹可以添加为播放源，与本地文件夹一起参与「播放全部」。
- **远程播放**：远端视频支持拖动进度条（HTTP Range），播放体验与本地文件一致。
- **远程排除播放**：共享方允许时，可把远端视频标记为「排除播放」，不会删除对方磁盘上的文件。
- **复制到本地**：共享方允许时，可把远端视频复制到本机，支持进度显示、取消与断点续传。
- **断线自动重连**：共享设备暂时离线后会自动重试，恢复后无需重新添加。
- **封面缓存**：共享文件夹的封面保存在本地，网络波动或离线时仍能正常显示。

### 桌面端系统托盘

- 可在「内网共享」页开启「关闭时最小化到托盘」，关闭窗口后程序继续在托盘运行，共享服务不中断。
- 托盘图标支持左键单击显示主界面、右键弹出菜单。

### 选择视频页

- 新增「添加共享源」，可直接从共享源中选择要播放的文件夹。
- 本地文件夹与共享文件夹分区展示，支持「播放全部」「重新连接全部」。
- 已排除的视频按文件夹分组管理，可整组「恢复文件」「删除文件」。

## 改进

- **统一的排序菜单**：瀑布流提供 8 种排序（名称升降、时间新旧、大小升降、随机、新视频优先），
  每个文件夹会记住自己的排序方式。
- **按列表顺序播放**：从瀑布流进入播放时，严格按当前排序播放，不再受设置页的随机模式影响。
- **返回自动刷新**：从播放页或子页面返回时，列表、统计与排除状态即时更新，不丢失滚动位置。
- **首页按钮更名为「选择视频」**：与该页面实际管理的播放源保持一致。
- **启动清理**：自动清理超过 7 天的未完成复制分片，避免长期占用磁盘空间。
- **CI 质量门禁**：发布前强制执行静态分析与单元测试，任一失败即终止构建。

## 问题修复

- **退出播放后仍在后台出声**：系统返回键、返回手势、工具栏返回等所有退出路径都会立即停止播放；
  同时保证任何时刻只有一个播放器实例在出声，打开新视频一定会打断旧视频。
- **共享视频缩略图取不到**：修复了服务端解析路径时把 Windows 路径转成正斜杠、
  导致系统缩略图接口失败的问题，远端瀑布流现在可以正常显示缩略图。
- **拖动音量条导致崩溃**：调整音量时只做本地预览，松手后一次性生效，并屏蔽该弹层的无障碍访问，
  避免 Android 无障碍层递归耗尽线程栈。
- 播放页工具栏点击不再误隐藏；自动隐藏只在无操作后开始计时。

---

## 行为说明

- 内网共享使用端口 **48321（HTTP）** 与 **48322（UDP 发现）**，与其他应用互不影响。
- 共享默认只读：远程操作仅限于共享方允许的「排除播放」与「复制」，不会删除或修改共享方的文件。
- 端口与设备 ID 变化后，新旧版本互不发现；升级到 v1.2.0 后同版本设备可正常自动发现。
- 原有设置、已选文件夹与已排除记录会完整保留，可直接覆盖安装。

## 安装包

| 平台 | 文件 | 说明 |
|------|------|------|
| **Windows** | `SteamFlow-v1.2.0-windows-x64.zip` | 解压后运行 `SteamFlow.exe`（64 位） |
| **Android** | `SteamFlow-v1.2.0-android.apk` | APK 安装包，需允许「安装未知来源应用」 |

### Windows

1. 下载并解压 `SteamFlow-v1.2.0-windows-x64.zip`
2. 双击 `SteamFlow.exe` 运行，无需安装

### Android

1. 下载 `SteamFlow-v1.2.0-android.apk` 并传到手机
2. 点击安装；若提示「未知来源」，在系统设置中允许该应用安装未知应用

> 从 v1.1.x 升级可直接覆盖安装，设置与播放记录都会保留。

## 主要功能一览

- **播放控制**：顺序 / 逆序 / 由新到旧 / 由旧到新 / 随机 / 新视频优先；循环播放、自动播放、单一循环
- **视频显示**：适应窗口 / 填满窗口 / 原始大小、背景底色、屏幕方向、缩放（最高 5 倍）、旋转、拖拽平移
- **瀑布流浏览**：本地与共享统一的 8 种排序、按当前排序播放、文件信息显示（文件名 / 日期 / 大小）
- **切换动画**：淡入淡出、左右滑动、上下滑动、无动画，时长可调
- **工具栏**：自动隐藏、暂停时保持、视频信息显示
- **视频管理**：排除播放、实际删除、已排除视频按文件夹分组恢复 / 删除
- **内网共享**：设备发现、共享文件夹、混合播放、远程排除、复制到本地、断点续传、断线重连
- **系统托盘**（Windows）：关闭窗口后继续在后台共享
- **多语言**：简体中文 / 繁體中文 / English
- **格式支持**：mp4 / m4v / mov / mkv / webm / avi / wmv 等
