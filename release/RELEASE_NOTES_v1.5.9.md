# SteamFlow v1.5.9 发布说明

> SteamFlow — 基于 Flutter 的跨平台视频播放器。
> 无广告、完全免费，可自由分享。

---

## 本版本主题：提示更完整，版本信息更准确

v1.5.9 是一个小版本更新：补齐了快捷键列表里的 Enter 说明，
并修正了首页与「关于」页长期显示旧版本号的问题。

---

## 新增与改进

### 快捷键列表补充 Enter

- 设置页「内置快捷键」新增 Enter：开始播放。
- 与首页「开始播放」、浏览页 Enter 从头播放的行为保持一致。

---

## 问题修复

### 版本号显示过旧

- 首页底部的版本号与「关于」页的版本信息此前仍显示 V1.3.5，
  现已与安装包版本同步为 V1.5.9。

## 安装包

| 平台 | 文件 | 说明 |
|------|------|------|
| **Windows** | `SteamFlow-v1.5.9-windows-x64.zip` | 解压后运行 `SteamFlow.exe`（64 位） |
| **Android** | `SteamFlow-v1.5.9-android.apk` | APK 安装包，需允许「安装未知来源应用」 |

### Windows

1. 下载并解压 `SteamFlow-v1.5.9-windows-x64.zip`
2. 双击 `SteamFlow.exe` 运行，无需安装

### Android

1. 下载 `SteamFlow-v1.5.9-android.apk` 并传到手机
2. 点击安装；若提示「未知来源」，在系统设置中允许该应用安装未知应用

---

## 升级说明

- 从 v1.5.8（或更早版本）直接**覆盖安装**即可：设置、媒体库、已选文件夹、
  共享源、排除记录、播放进度都会保留。
- 版本号与姐妹应用 FrameFlow 对齐到 1.5.9。

## 主要功能一览

- **多媒体库**：多个互不关联的视频库，独立管理本地与共享文件夹、排除记录，支持隐藏
- **播放控制**：顺序 / 逆序 / 由新到旧 / 由旧到新 / 随机 / 新视频优先；循环、自动播放、单一循环
- **接续播放**：记录每个视频进度，下次从上次位置继续；播放完毕自动清除
- **倍速播放**：0.75× / 1× / 1.25× / 1.5× / 2× / 3×
- **音轨 / 字幕**：选择内嵌音轨与字幕，按视频记住选择
- **字幕样式**：自定义字体与字号，播放中可一键加大 / 减小
- **屏幕方向**：横屏 / 竖屏 / 跟随系统 / 跟随视频
- **上下翻转**：手机整界面翻转，电脑只翻画面
- **视频显示**：适应窗口 / 填满窗口 / 原始大小、缩放、拖拽平移
- **浏览格式**：瀑布流 / 正方形 / 横屏 4:3、16:9 / 竖屏 3:4、9:16
- **瀑布流浏览**：本地与共享统一的 8 种排序（中文拼音 + 自然排序）、按当前排序播放
- **视频管理**：排除播放、删除到回收站、已排除视频按文件夹分组恢复 / 删除
- **内网共享**：设备发现、共享文件夹、混合播放、远程排除、复制到本地、断点续传、断线重连
- **桌面集成**（Windows）：单实例与文件直开、右键菜单、设为默认播放器、系统托盘
- **多语言**：简体中文 / 繁體中文 / English
- **格式支持**：mp4 / m4v / mov / mkv / webm / avi / wmv 等
