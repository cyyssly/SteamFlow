# SteamFlow v1.3.0 发布说明

> SteamFlow — 基于 Flutter 的跨平台视频播放器。
> 无广告、完全免费，可自由分享。

---

## 本版本主题：更顺手的桌面体验

v1.3.0 让 SteamFlow 融入 Windows 日常使用：支持**单实例与文件直开**、系统**右键菜单**和
**默认播放器**注册，播放器新增**接续播放**、**倍速播放**与**关闭按钮**；桌面右键菜单也
重构为更快、更接近系统原生观感的级联菜单。

---

## 新增功能

### Windows 单实例与文件直开

- **单实例互斥**：同时只允许一个 SteamFlow 进程，重复启动会把窗口带到前台。
- **文件路径转发**：双击视频文件、或在系统右键菜单里选择「用 SteamFlow 播放」时，
  若已有实例在运行，直接在现有窗口打开该视频，不会弹出第二个窗口。

### 桌面右键菜单

- 为视频格式（mp4 / m4v / mov / mkv / webm / avi / wmv 等）注册「用 SteamFlow 播放」右键项。
- **启动自愈**：应用被移动或重命名后，下次启动会自动把注册表里的路径改写为当前程序位置，
  并把设置页开关自动打开，右键菜单不会因此失效。

### 设为默认播放器

- 设置页一键把 SteamFlow 注册为视频格式的候选默认播放器，并打开系统「默认应用」设置页，
  在「视频播放器」中选中 SteamFlow 即可把视频默认交给它播放。

### 播放器关闭按钮（Windows）

- 播放页右上角新增关闭按钮。按「快捷键与控制」里的设置，可直接退出程序，
  或在「关闭时最小化到托盘」开启时退到系统托盘继续运行。

### 接续播放

- 设置页「播放设置」新增「接续播放」：记录每个视频的播放进度（本地保存），
  下次进入时从上次位置继续播放；也可改为「从头播放」。视频播放完毕会清除记录。

### 倍速播放

- 支持 0.75× / 1× / 1.25× / 1.5× / 2× / 3×。
- 手机端：工具栏下方新增独立的倍速行，点击即可切换。
- 桌面端：右键菜单「播放速度」以级联菜单选择档位，换片后保持当前倍速。

### 浏览格式

- 瀑布流页新增 6 种浏览格式：瀑布流（按视频原始比例）、正方形、横屏 4:3 / 16:9、竖屏 3:4 / 9:16；
  每个文件夹可单独设置，未设置时跟随设置页默认值。

### 手机端短按行为

- 设置页「快捷键与控制」新增「短按行为」：单击视频可设为「播放」或「选中」。

---

## 改进

- **桌面右键菜单重构**：改为自定义级联菜单，弹出更快；展开「播放速度」二级菜单时
  一级菜单保持显示，点击具体档位后整体关闭，交互更接近系统右键菜单。
- **换片动画统一**：固定 0.3 秒，方向随触发来源自动选择（滚轮/手势上下滑动、
  工具栏/方向键左右滑动、播放结束淡入淡出）。
- **多语言化**：右键菜单、默认播放器注册与设置文案随界面语言切换（简体中文 / 繁體中文 / English），
  注册表里的文案会按当前语言自动重写。

---

## 问题修复

- **右键菜单失效**：应用路径变更或临时副本被删除后，右键菜单点击无反应 —— 现已通过启动自愈自动修复。
- **二级菜单交互**：展开「播放速度」时一级菜单不再先关闭再弹出，消除闪烁与迟滞感。
- **播放器无法快速关闭**：桌面版播放页新增关闭按钮，不再需要先退出全屏。

---

## 行为说明

- 单实例与文件转发仅在 Windows 生效；Android 上仍按原有方式启动播放。
- 接续播放进度保存在本地（`videoProgress`），卸载应用才会清除。
- 右键菜单与默认播放器注册以当前语言写入注册表；切换语言后会自动重写。
- 原有设置、已选文件夹、已排除记录与播放进度会完整保留，可直接覆盖安装。

## 安装包

| 平台 | 文件 | 说明 |
|------|------|------|
| **Windows** | `SteamFlow-v1.3.0-windows-x64.zip` | 解压后运行 `SteamFlow.exe`（64 位） |
| **Android** | `SteamFlow-v1.3.0-android.apk` | APK 安装包，需允许「安装未知来源应用」 |

### Windows

1. 下载并解压 `SteamFlow-v1.3.0-windows-x64.zip`
2. 双击 `SteamFlow.exe` 运行，无需安装

### Android

1. 下载 `SteamFlow-v1.3.0-android.apk` 并传到手机
2. 点击安装；若提示「未知来源」，在系统设置中允许该应用安装未知应用

> 从 v1.2.x 升级可直接覆盖安装，设置与播放进度都会保留。

## 主要功能一览

- **播放控制**：顺序 / 逆序 / 由新到旧 / 由旧到新 / 随机 / 新视频优先；循环播放、自动播放、单一循环
- **接续播放**：记录每个视频进度，下次从上次位置继续；播放完毕自动清除
- **倍速播放**：0.75× / 1× / 1.25× / 1.5× / 2× / 3×（手机端工具栏行、桌面端右键菜单）
- **视频显示**：适应窗口 / 填满窗口 / 原始大小、背景底色、屏幕方向、缩放（最高 5 倍）、旋转、拖拽平移
- **浏览格式**：瀑布流 / 正方形 / 横屏 4:3、16:9 / 竖屏 3:4、9:16
- **瀑布流浏览**：本地与共享统一的 8 种排序、按当前排序播放、文件信息显示（文件名 / 日期 / 大小）
- **切换动画**：0.3 秒固定时长，方向随触发来源自动选择
- **工具栏**：自动隐藏、暂停时保持、视频信息显示
- **视频管理**：排除播放、实际删除、已排除视频按文件夹分组恢复 / 删除
- **内网共享**：设备发现、共享文件夹、混合播放、远程排除、复制到本地、断点续传、断线重连
- **桌面集成**（Windows）：单实例与文件直开、右键菜单（带启动自愈）、设为默认播放器、系统托盘
- **多语言**：简体中文 / 繁體中文 / English
- **格式支持**：mp4 / m4v / mov / mkv / webm / avi / wmv 等
