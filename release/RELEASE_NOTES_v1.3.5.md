# SteamFlow v1.3.5 发布说明

> SteamFlow — 基于 Flutter 的跨平台视频播放器。
> 无广告、完全免费，可自由分享。

---

## 本版本主题：媒体库更完整，播放更稳

v1.3.5 让「已排除文件」也跟着媒体库走，并修复了两个影响日常使用的小问题：
浏览页排除文件后一直转圈、手机端连续播放横屏视频时会先转竖屏。

---

## 新增与改进

### 已排除文件按媒体库隔离

- 在哪个媒体库里排除的视频，只在该库生效；切换到其他库后，这些视频会正常播放。
- 「已排除」列表也只显示当前库的记录，恢复 / 删除操作同样只影响当前库。
- 同一个视频可以在不同库分别决定是否排除。
- 升级时，原有的排除记录会自动归入当前库，与升级前保持一致。

### 姐妹应用 FrameFlow

- 帮助页「关于」分区新增 FrameFlow 的简介与链接。
- FrameFlow 是同一作者开发的跨平台图片幻灯片应用：**视频用 SteamFlow，图片用 FrameFlow**。
- 项目主页：https://github.com/cyyssly/FrameFlow

## 问题修复

### 浏览页排除文件后一直显示加载提示

浏览文件夹时，中途排除 / 删除部分视频后再滑到列表底部，加载提示会一直转圈，
无法正常结束分页。已修正预加载计数与列表长度的同步，滑到底部能正常加载完成。

### 「跟随视频」时横屏视频之间多转一次竖屏

手机端方向设置为「跟随视频」时，播放完一个横屏视频后，即使下一个还是横屏视频，
也会先转成竖屏再转回横屏。现在换片时会沿用上一个视频的朝向，同朝向的视频之间
不再出现多余旋转；横竖屏不同时仍然只转一次到正确方向。

## 安装包

| 平台 | 文件 | 说明 |
|------|------|------|
| **Windows** | `SteamFlow-v1.3.5-windows-x64.zip` | 解压后运行 `SteamFlow.exe`（64 位） |
| **Android** | `SteamFlow-v1.3.5-android.apk` | APK 安装包，需允许「安装未知来源应用」 |

### Windows

1. 下载并解压 `SteamFlow-v1.3.5-windows-x64.zip`
2. 双击 `SteamFlow.exe` 运行，无需安装

### Android

1. 下载 `SteamFlow-v1.3.5-android.apk` 并传到手机
2. 点击安装；若提示「未知来源」，在系统设置中允许该应用安装未知应用

---

## 升级说明

- 从 v1.3.3（或更早版本）直接**覆盖安装**即可：设置、媒体库、已选文件夹、
  共享源、排除记录、播放进度都会保留。
- 已排除记录会按库重新组织：升级前的排除项全部归入当时正在使用的媒体库。

## 主要功能一览

- **多媒体库**：多个互不关联的视频库，独立管理本地与共享文件夹、排除记录，支持隐藏
- **播放控制**：顺序 / 逆序 / 由新到旧 / 由旧到新 / 随机 / 新视频优先；循环、自动播放、单一循环
- **接续播放**：记录每个视频进度，下次从上次位置继续；播放完毕自动清除
- **倍速播放**：0.75× / 1× / 1.25× / 1.5× / 2× / 3×
- **音轨 / 字幕**：选择内嵌音轨与字幕，按视频记住选择
- **字幕样式**：自定义字体与字号，播放中可一键加大 / 减小
- **屏幕方向**：横屏 / 竖屏 / 跟随系统 / 跟随视频
- **上下翻转**：手机整界面翻转，电脑只翻画面
- **视频显示**：适应窗口 / 填满窗口 / 原始大小、缩放、拖拽平移
- **浏览格式**：瀑布流 / 正方形 / 横屏 4:3、16:9 / 竖屏 3:4、9:16
- **瀑布流浏览**：本地与共享统一的 8 种排序（中文拼音 + 自然排序）、按当前排序播放
- **视频管理**：排除播放、实际删除、已排除视频按文件夹分组恢复 / 删除
- **内网共享**：设备发现、共享文件夹、混合播放、远程排除、复制到本地、断点续传、断线重连
- **桌面集成**（Windows）：单实例与文件直开、右键菜单、设为默认播放器、系统托盘
- **多语言**：简体中文 / 繁體中文 / English
- **格式支持**：mp4 / m4v / mov / mkv / webm / avi / wmv 等
