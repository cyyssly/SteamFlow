# SteamFlow v1.3.3 发布说明

> SteamFlow — 基于 Flutter 的跨平台视频播放器。
> 无广告、完全免费，可自由分享。

---

## 本版本主题：一个应用，多个独立视频库

v1.3.3 新增「媒体库」，你可以把电影、剧集、课程等分开管理，互不干扰；
同时新增字幕字体与字号设置，并修复了几处弹窗导致的崩溃。

---

## 新增功能

### 1. 媒体库（入口在「选择视频」页右上角）

- 可以**新建、重命名、删除、切换**多个媒体库。
- 每个库都有自己独立的**本地文件夹**和**共享文件夹**，不同库之间完全不混在一起。
- 同一个文件夹可以同时放进多个库，方便做「合集」。
- 双击电脑上的视频文件时，应用会**自动切换到该视频所属的库**；
  视频不属于任何库时保持当前库不变。
- 旧版本升级后，原有文件夹会自动归入一个「默认媒体库」，无需重新添加。

### 2. 隐藏媒体库

- 在媒体库菜单里可以「隐藏 / 取消隐藏」某个库。
- 设置页「文件与目录」组新增开关 **「显示隐藏媒体库」**：
  - 关闭（默认）：隐藏的库不出现在媒体库列表里。
  - 打开：隐藏的库会以**半透明样式**显示，方便随时取消隐藏。
- 关闭开关时，如果当前库正好是隐藏库，会自动切换到第一个可见的库。

### 3. 字幕样式

- 设置页新增独立的 **「字幕样式」** 分组：
  - **字幕字体**：填写系统已安装的字体名（默认 `sans-serif`）。
  - **字幕字号**：可在 20–120 之间调整。
- 播放界面右键菜单 / 手机工具栏菜单新增 **「字幕加大」「字幕减小」**，
  点一下立即生效（每次 ±5），也可以随手快速调整大小。
- 说明：SRT 等文本字幕直接生效；ASS/SSA 字幕会以这里设置的字体和字号
  覆盖文件自带的排版样式；PGS 等图片字幕不受影响。

### 4. 左右方向键行为可配置

- 设置页「快捷键与设置」组新增 **「左右箭头行为」**：
  - **前进/后退**（默认）：每次跳到进度条的 5%。
  - **切换视频**：上一个 / 下一个视频。
- 另一种行为可用 `Ctrl + 左右箭头` 触发。

## 改进

- **手机端同名文件夹自动合并**：所有同名的本地文件夹会归并为一个条目，
  数量统计、播放、浏览、移除都按合并后的整体处理，列表更清爽。
- **默认库名称跟随语言**：语言设为「跟随系统」时，默认媒体库名称会按
  系统语言显示（简体 / 繁体 / English）。
- **播放页字幕快捷调整**：不用进入设置页也能临时放大 / 缩小字幕。

---

## 问题修复

- 修复「新建 / 重命名媒体库」弹窗关闭后偶发崩溃（`TextEditingController`
  被提前释放）。
- 修复「字幕字体」与「手动输入共享设备地址」弹窗存在同样的崩溃隐患。
- 修复旧版本升级后，已添加的共享文件夹在新库中不可见的问题
  （升级时自动归入当前库）。

## 安装包

| 平台 | 文件 | 说明 |
|------|------|------|
| **Windows** | `SteamFlow-v1.3.3-windows-x64.zip` | 解压后运行 `SteamFlow.exe`（64 位） |
| **Android** | `SteamFlow-v1.3.3-android.apk` | APK 安装包，需允许「安装未知来源应用」 |

### Windows

1. 下载并解压 `SteamFlow-v1.3.3-windows-x64.zip`
2. 双击 `SteamFlow.exe` 运行，无需安装

### Android

1. 下载 `SteamFlow-v1.3.3-android.apk` 并传到手机
2. 点击安装；若提示「未知来源」，在系统设置中允许该应用安装未知应用

## 升级说明

- 从 v1.3.2 直接**覆盖安装**即可：设置、已选文件夹、共享源、排除记录、
  播放进度都会保留。
- 原有文件夹与共享文件夹会自动归入「默认媒体库」，之后可以重命名，
  或新建其他库再自由分配。

## 主要功能一览

- **多媒体库**：多个互不关联的视频库，独立管理本地与共享文件夹，支持隐藏
- **播放控制**：顺序 / 逆序 / 由新到旧 / 由旧到新 / 随机 / 新视频优先；循环、自动播放、单一循环
- **接续播放**：记录每个视频进度，下次从上次位置继续；播放完毕自动清除
- **倍速播放**：0.75× / 1× / 1.25× / 1.5× / 2× / 3×
- **音轨 / 字幕**：选择内嵌音轨与字幕，按视频记住选择
- **字幕样式**：自定义字体与字号，播放中可一键加大 / 减小
- **屏幕方向**：横屏 / 竖屏 / 跟随系统 / 跟随视频
- **上下翻转**：手机整界面翻转，电脑只翻画面
- **视频显示**：适应窗口 / 填满窗口 / 原始大小、缩放、拖拽平移
- **浏览格式**：瀑布流 / 正方形 / 横屏 4:3、16:9 / 竖屏 3:4、9:16
- **瀑布流浏览**：本地与共享统一的 8 种排序（中文拼音 + 自然排序）、按当前排序播放
- **视频管理**：排除播放、实际删除、已排除视频按文件夹分组恢复 / 删除
- **内网共享**：设备发现、共享文件夹、混合播放、远程排除、复制到本地、断点续传、断线重连
- **桌面集成**（Windows）：单实例与文件直开、右键菜单、设为默认播放器、系统托盘
- **多语言**：简体中文 / 繁體中文 / English
- **格式支持**：mp4 / m4v / mov / mkv / webm / avi / wmv 等
