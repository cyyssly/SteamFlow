# SteamFlow v1.3.1 发布说明

> SteamFlow — 基于 Flutter 的跨平台视频播放器。
> 无广告、完全免费，可自由分享。

---

## 本版本主题：手机端横竖屏更好用

v1.3.1 重点打磨手机端播放页：**一键横竖屏切换**、**每个视频记住自己的方向**，
并让横屏下的工具栏更紧凑、不再遮挡画面。同时补上**音轨 / 字幕选择**，
文件名排序也改为**中文拼音 + 自然排序**。

---

## 新增功能

### 手机端横竖屏一键切换

- 播放页进度条右侧新增切换按钮，点击即在横屏 / 竖屏之间切换，
  视频画面与播放界面一起转向。
- 切换只影响当前这次播放，**不会改动设置里的方向偏好**；退出播放页后自动恢复。
- 仅在 Android / iOS 显示，桌面端保持原样。

### 每个视频记住自己的方向

- 某个视频手动切到横屏后，下次再播放它会**自动回到横屏**；
  没切过的视频继续跟随设置里的方向偏好。
- 播放中左右滑动换片时，也会按各自记录的方向自动切换。

### 音轨与字幕选择

- 播放页菜单（⋮）与桌面右键菜单新增「声道」「字幕」两个级联入口，
  可直接选择内嵌音轨与字幕轨道。
- 每个视频会**记住上次选择**，下次播放自动应用。

### 中文拼音 / 自然排序

- 文件名排序支持**中文按拼音**排列，数字按大小排列
  （例如「第2集」排在「第10集」前），浏览列表、播放顺序、
  内网共享列表与文件夹排序全部统一。

### 文件直开更聪明

- 双击视频文件（或在系统右键菜单里选「用 SteamFlow 播放」）时，
  会**自动加载同目录的视频**并按该文件夹 / 默认排序排列，
  从你点开的那个视频开始播放，切换上一个 / 下一个即可顺次浏览。

### 其他

- 手机端主页「选择相册」改为「选择视频」，图标也换成视频图标。

---

## 改进

- **横屏工具栏更紧凑**：播放键缩到与相邻按钮同尺寸，进度条压扁，
  进度条与按钮行之间的空隙大幅收紧，横屏时画面可视区域更大。
- **菜单更紧凑**：菜单行高收紧；空间不足时子菜单自动避让屏幕边缘、
  导航栏与挖孔区域，不再贴边显示。
- **菜单精简**：移除「适应屏幕」，倍速改由菜单选择（手机端不再单独占一行）。
- **主页按钮**：文案过长时不再溢出。

---

## 问题修复

- 横屏下展开「播放速度」子菜单时，底部选项被屏幕裁掉。
- 子菜单贴底时被系统导航栏遮挡。
- 手机横屏时底部按钮行被屏幕边缘切掉一部分。

---

## 行为说明

- 横竖屏记忆按视频保存，保存在本地（与音轨 / 字幕偏好同一份记录），卸载应用才会清除。
- 从 v1.3.0 覆盖安装即可，**设置、已选文件夹、排除记录、播放进度与方向记忆都会保留**。

## 安装包

| 平台 | 文件 | 说明 |
|------|------|------|
| **Windows** | `SteamFlow-v1.3.1-windows-x64.zip` | 解压后运行 `SteamFlow.exe`（64 位） |
| **Android** | `SteamFlow-v1.3.1-android.apk` | APK 安装包，需允许「安装未知来源应用」 |

### Windows

1. 下载并解压 `SteamFlow-v1.3.1-windows-x64.zip`
2. 双击 `SteamFlow.exe` 运行，无需安装

### Android

1. 下载 `SteamFlow-v1.3.1-android.apk` 并传到手机
2. 点击安装；若提示「未知来源」，在系统设置中允许该应用安装未知应用

> 从 v1.3.0 升级可直接覆盖安装，设置与播放进度都会保留。

## 主要功能一览

- **播放控制**：顺序 / 逆序 / 由新到旧 / 由旧到新 / 随机 / 新视频优先；循环播放、自动播放、单一循环
- **接续播放**：记录每个视频进度，下次从上次位置继续；播放完毕自动清除
- **倍速播放**：0.75× / 1× / 1.25× / 1.5× / 2× / 3×（菜单内选择，换片后保持）
- **音轨 / 字幕**：选择内嵌音轨与字幕，按视频记住选择
- **横竖屏**：手机端一键切换，按视频记住方向
- **视频显示**：适应窗口 / 填满窗口 / 原始大小、背景底色、屏幕方向、缩放（最高 5 倍）、旋转、拖拽平移
- **浏览格式**：瀑布流 / 正方形 / 横屏 4:3、16:9 / 竖屏 3:4、9:16
- **瀑布流浏览**：本地与共享统一的 8 种排序（中文拼音 + 自然排序）、按当前排序播放、文件信息显示
- **切换动画**：0.3 秒固定时长，方向随触发来源自动选择
- **工具栏**：自动隐藏、暂停时保持、视频信息显示
- **视频管理**：排除播放、实际删除、已排除视频按文件夹分组恢复 / 删除
- **内网共享**：设备发现、共享文件夹、混合播放、远程排除、复制到本地、断点续传、断线重连
- **桌面集成**（Windows）：单实例与文件直开、右键菜单（带启动自愈）、设为默认播放器、系统托盘
- **多语言**：简体中文 / 繁體中文 / English
- **格式支持**：mp4 / m4v / mov / mkv / webm / avi / wmv 等
