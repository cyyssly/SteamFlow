# SteamFlow v1.3.2 发布说明

> SteamFlow — 基于 Flutter 的跨平台视频播放器。
> 无广告、完全免费，可自由分享。

---

## 本版本主题：横竖屏更顺手，桌面缩略图更清晰

v1.3.2 重新整理了「屏幕方向」的行为，让手机和电脑各按各的方式工作；
手机播放菜单精简并新增「上下翻转」；桌面浏览页的缩略图会按你屏幕的实际
分辨率自动变清晰。

---

## 新增功能

### 上下翻转

- 手机播放菜单新增「上下翻转」：点一下，整个播放界面（工具栏 + 画面）
  一起上下颠倒，适合手机倒挂、躺着看等姿势。
- 电脑上点「上下翻转」只翻视频画面，界面保持原样。

### 屏幕方向按平台各司其职

| 设置项 | 手机 | 电脑 |
|---|---|---|
| **横屏 / 竖屏** | 整个播放界面连画面一起转 | 只旋转视频画面，界面不动 |
| **跟随系统** | 跟随手机重力感应 | 不变 |
| **跟随视频** | 自动把界面转成视频的方向（横屏视频→横屏界面） | 只旋转视频画面 |

### 桌面缩略图更清晰

- 缩略图不再固定 512 像素，改为按「卡片实际需要的像素」自动取档
  （512 / 768 / 1024 / 1536）。
- 把窗口拉宽、或系统缩放调高到 150%/200% 时，可见卡片会在瞬间换成更清晰的一张。
- 1080p 屏保持原来的清晰度与内存占用，4K / 高缩放屏幕上不再发虚。

## 改进

- **手机播放菜单更简洁**：去掉「放大 / 缩小 / 旋转」——缩放用双指手势，
  旋转交给横竖屏切换按钮；菜单变成：上下翻转 → 播放速度 → 声道 → 字幕。
- **方向不再“记仇”**：以前某个视频会被记住上次手动切的方向，现在取消记忆，
  每次播放都按设置走（方向其实只跟你当时的观看姿势有关，跟视频本身无关）。
- **横屏工具栏更紧凑**：进度条压扁并与按钮行贴紧、右侧切换按钮与进度条对齐、
  顶部栏高度从 56 压到 40，横屏时画面可视区域更大。
- **真正的沉浸式全屏**：播放时连底部的手势横线一起隐藏。
- **设置页精简**：去掉「背景底色」，播放背景统一为黑色。

## 问题修复

- 横屏下展开「播放速度」子菜单，底部选项被屏幕裁掉。
- 子菜单贴底时被系统导航栏遮住一部分。
- 手机横屏时底部按钮行被屏幕边缘切掉。
- 手机从横屏切回竖屏后，界面转了、视频却还横着（画面躺倒）。
- 手机「跟随视频」时视频转了、播放界面仍是竖屏。

## 行为说明

- 播放进度记忆、按视频记住的音轨 / 字幕选择**都还在**，只是不再记忆屏幕方向。
- 从 v1.3.1 直接覆盖安装即可，设置、已选文件夹、排除记录、播放进度都会保留。

## 安装包

| 平台 | 文件 | 说明 |
|------|------|------|
| **Windows** | `SteamFlow-v1.3.2-windows-x64.zip` | 解压后运行 `SteamFlow.exe`（64 位） |
| **Android** | `SteamFlow-v1.3.2-android.apk` | APK 安装包，需允许「安装未知来源应用」 |

### Windows

1. 下载并解压 `SteamFlow-v1.3.2-windows-x64.zip`
2. 双击 `SteamFlow.exe` 运行，无需安装

### Android

1. 下载 `SteamFlow-v1.3.2-android.apk` 并传到手机
2. 点击安装；若提示「未知来源」，在系统设置中允许该应用安装未知应用

## 主要功能一览

- **播放控制**：顺序 / 逆序 / 由新到旧 / 由旧到新 / 随机 / 新视频优先；循环播放、自动播放、单一循环
- **接续播放**：记录每个视频进度，下次从上次位置继续；播放完毕自动清除
- **倍速播放**：0.75× / 1× / 1.25× / 1.5× / 2× / 3×（菜单内选择，换片后保持）
- **音轨 / 字幕**：选择内嵌音轨与字幕，按视频记住选择
- **屏幕方向**：横屏 / 竖屏 / 跟随系统 / 跟随视频（手机整界面旋转，电脑只转画面）
- **上下翻转**：手机整界面翻转，电脑只翻画面
- **视频显示**：适应窗口 / 填满窗口 / 原始大小、缩放（最高 5 倍）、拖拽平移
- **浏览格式**：瀑布流 / 正方形 / 横屏 4:3、16:9 / 竖屏 3:4、9:16
- **瀑布流浏览**：本地与共享统一的 8 种排序（中文拼音 + 自然排序）、按当前排序播放、文件信息显示
- **切换动画**：0.3 秒固定时长，方向随触发来源自动选择
- **工具栏**：自动隐藏、暂停时保持、视频信息显示
- **视频管理**：排除播放、实际删除、已排除视频按文件夹分组恢复 / 删除
- **内网共享**：设备发现、共享文件夹、混合播放、远程排除、复制到本地、断点续传、断线重连
- **桌面集成**（Windows）：单实例与文件直开、右键菜单（带启动自愈）、设为默认播放器、系统托盘
- **多语言**：简体中文 / 繁體中文 / English
- **格式支持**：mp4 / m4v / mov / mkv / webm / avi / wmv 等
