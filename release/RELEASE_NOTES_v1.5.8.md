# SteamFlow v1.5.8 发布说明

> SteamFlow — 基于 Flutter 的跨平台视频播放器。
> 无广告、完全免费，可自由分享。

---

## 本版本主题：打开更快，顺序更准，操作更顺手

v1.5.8 重点优化了「双击打开视频」的体验：打开瞬间就显示你点的那个视频，
同文件夹的播放顺序也与资源管理器里看到的完全一致。同时补齐了多个日常操作细节。

---

## 新增与改进

### 双击打开更快

- 双击视频后立即进入播放页显示该视频，不再先播放上一个视频再切换。
- 同文件夹的播放列表改为在后台扫描，扫完后原地补全，观看过程不中断。

### 播放顺序与资源管理器一致

- 双击打开时，按视频所在文件夹在资源管理器中的当前排序建立播放列表。
- 支持按名称、修改日期、大小的升序 / 降序排列。
- 读取不到排序信息时，回退到按文件名自然排序（`视频2` 排在 `视频10` 之前）。

### 媒体库一次添加多个文件夹

- 桌面端选择文件夹时支持多选，一次即可把多个文件夹加入媒体库。
- 已添加的文件夹会自动去重，并显示各自的视频数量。

### 按住方向键连续缩放

- 播放页按住 ↑ / ↓ 可连续放大 / 缩小，按住即可持续变化，无需反复点按。

### 浏览页排序更快

- 排序时复用已生成的排序键，避免重复比较与重复解析文件名。
- Windows 下使用系统原生比较规则，中文、数字、大小写混合的文件名排序与资源管理器一致。

### 共享文件夹状态更准确

- 共享源是否可用改为按「文件夹」判断：设备在线但已不再共享某个文件夹时，
  该文件夹会正确显示为离线，而不是仍然可以点开。

---

## 问题修复

### 删除确认对话框期间误切换视频

删除确认框打开后，方向键、点击等切换操作不再生效，避免在确认过程中切走正在删除的视频。

### 放大状态下换片仍保持放大

删除当前视频或切换到其他视频时，会重置缩放与平移状态，新视频以正常比例显示。

### 删除文件改为进入回收站

- Windows：通过系统 Shell 移入回收站，误删可从回收站还原。
- Android 11 及以上：通过 MediaStore 移入系统回收站。
- 回收站操作失败时不会退化为永久删除，避免误删文件。

### 文件夹信息多余文字

文件夹没有子文件夹时，不再显示「包含 0 个子文件夹」，只显示文件数量。

## 安装包

| 平台 | 文件 | 说明 |
|------|------|------|
| **Windows** | `SteamFlow-v1.5.8-windows-x64.zip` | 解压后运行 `SteamFlow.exe`（64 位） |
| **Android** | `SteamFlow-v1.5.8-android.apk` | APK 安装包，需允许「安装未知来源应用」 |

### Windows

1. 下载并解压 `SteamFlow-v1.5.8-windows-x64.zip`
2. 双击 `SteamFlow.exe` 运行，无需安装

### Android

1. 下载 `SteamFlow-v1.5.8-android.apk` 并传到手机
2. 点击安装；若提示「未知来源」，在系统设置中允许该应用安装未知应用

## 升级说明

- 从 v1.3.5（或更早版本）直接**覆盖安装**即可：设置、媒体库、已选文件夹、
  共享源、排除记录、播放进度都会保留。
- 版本号与姐妹应用 FrameFlow 对齐到 1.5.8。

## 主要功能一览

- **多媒体库**：多个互不关联的视频库，独立管理本地与共享文件夹、排除记录，支持隐藏
- **播放控制**：顺序 / 逆序 / 由新到旧 / 由旧到新 / 随机 / 新视频优先；循环、自动播放、单一循环
- **接续播放**：记录每个视频进度，下次从上次位置继续；播放完毕自动清除
- **倍速播放**：0.75× / 1× / 1.25× / 1.5× / 2× / 3×
- **音轨 / 字幕**：选择内嵌音轨与字幕，按视频记住选择
- **字幕样式**：自定义字体与字号，播放中可一键加大 / 减小
- **屏幕方向**：横屏 / 竖屏 / 跟随系统 / 跟随视频
- **上下翻转**：手机整界面翻转，电脑只翻画面
- **视频显示**：适应窗口 / 填满窗口 / 原始大小、缩放、拖拽平移
- **浏览格式**：瀑布流 / 正方形 / 横屏 4:3、16:9 / 竖屏 3:4、9:16
- **瀑布流浏览**：本地与共享统一的 8 种排序（中文拼音 + 自然排序）、按当前排序播放
- **视频管理**：排除播放、删除到回收站、已排除视频按文件夹分组恢复 / 删除
- **内网共享**：设备发现、共享文件夹、混合播放、远程排除、复制到本地、断点续传、断线重连
- **桌面集成**（Windows）：单实例与文件直开、右键菜单、设为默认播放器、系统托盘
- **多语言**：简体中文 / 繁體中文 / English
- **格式支持**：mp4 / m4v / mov / mkv / webm / avi / wmv 等
